# Image inbox

Drop the ChatGPT downloads here with the exact filenames from `IMAGE_PROMPTS.md`
(`hero-desktop.png`, `hero-mobile.png`, `engineer-thermal.png`, `tap-test.png`,
`laser-measure.png`, `handover-couple.png`, `crack-diagnosis.png`; `.webp` also works).

Then run `npm run images`. Originals in this folder are not committed; the optimised
files in `public/images/` are.
